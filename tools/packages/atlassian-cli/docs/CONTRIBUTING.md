# Contributing to Atlassian CLI

Thank you for your interest in contributing to the Atlassian CLI! This document provides guidelines and information for contributors.

---

## Getting Started

### Prerequisites

- Node.js 14+ installed
- npm or yarn
- Access to Jira and Confluence for testing

### Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/TD-Universe/easyapply-ai-workspace.git
   cd easyapply-ai-workspace/tools/atlassian-cli
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Link for local development:
   ```bash
   npm link
   ```

4. Configure your .env file (see [SETUP-ATL-CLI.md](../SETUP-ATL-CLI.md))

## Code Standards

### Style Guide

- Use ES6+ JavaScript features
- Follow existing code patterns
- Use meaningful variable/function names
- Add JSDoc comments for public functions

### Commit Messages

Follow the format: `{POD}-{TICKET#}: Description`

```bash
# AI-generated commits (required for AI contributions)
git commit -m "PROJ-123: Add new command" -m '' -m 'Generated by copilot: AI-A'
```

### Branch Naming

- Feature: `feature/ABC-987`
- Bugfix: `bugfix/DEF-456`
- Docs: `docs/description`

## Testing

### Running Tests

```bash
# Run all tests
npm test

# Run with coverage
npm test -- --coverage

# Run specific test file
npm test -- tests/unit/cache.test.js
```

### Writing Tests

- Place tests in `tests/unit/` directory
- Name files `*.test.js`
- Use fixtures from `tests/fixtures/`
- Aim for 90%+ code coverage

### Test Structure

```javascript
describe('ModuleName', () => {
  beforeEach(() => {
    // Setup
  });

  describe('functionName', () => {
    it('should do something specific', () => {
      // Arrange
      // Act
      // Assert
    });
  });
});
```

## Adding New Features

### Adding a New Command

1. Create command file in `src/commands/`:
   ```javascript
   function myCommand(program) {
     program
       .command('mycommand')
       .description('What it does')
       .action(async (options) => {
         // Implementation
       });
   }
   module.exports = myCommand;
   ```

2. Register in `bin/atl.js`:
   ```javascript
   const myCommand = require('../src/commands/mycommand');
   myCommand(program);
   ```

3. Add tests in `tests/unit/`

4. Document in `docs/COMMAND-REFERENCE.md`

### Adding an AI Skill

1. Create skill directory: `skills/my-skill/`
2. Add `SKILL.md` with proper frontmatter
3. Include usage examples
4. Test with GitHub Copilot

## Pull Request Process

1. Create a feature branch
2. Make your changes
3. Run tests: `npm test`
4. Update documentation if needed
5. Submit PR with clear description
6. Address review feedback

### PR Checklist

- [ ] Tests pass (`npm test`)
- [ ] Code follows style guide
- [ ] Documentation updated
- [ ] Commit messages follow format
- [ ] No sensitive data exposed

## Release Process

1. Update version in `package.json`
2. Update CHANGELOG.md
3. Create release PR
4. After merge, tag release: `git tag v0.0.2`
5. Push tags: `git push --tags`
