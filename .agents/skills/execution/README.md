# Execution stage

Skills for executing implementation increments, managing bugs, and creating PRs.

## Produces
- Implemented code in target repos
- Updated `increment-status.md` (formerly `phase-status.md`)
- Updated `bugs-and-issues-log.md`
- KB updates via the closing handoff to `skills/knowledge-base/update-knowledge-base/`

## Consumes
- Approved implementation package (with `INC-XXX` increments)
- The knowledge base for component context

## Skills (populated in task #6)
- `execute-increments/` — work increments through AI gate + human gate
- `manage-bugs/` — log / triage / resolve bugs via `bugs-and-issues-log.md`
- `create-pr/` — generate PR with summary and test plan
