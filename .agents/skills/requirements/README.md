# Requirements stage

Skills for gathering, analyzing, writing, and reviewing functional and non-functional requirements.

## Produces
A requirements package per `templates/compositions/greenfield-requirements-package.yaml` (or `brownfield-enhancement-spec.yaml` / `quick-dev-spec.yaml` depending on flow).

## Consumes
- Stakeholder input (elicited via `references/elicitation-patterns/stakeholder-discovery.md`)
- Reference materials (BRDs, mockups, prior tickets) from the user
- The knowledge base (in brownfield/quick-dev mode) via `skills/knowledge-base/navigate-knowledge-base/`
