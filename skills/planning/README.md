# Planning stage

Skills for breaking a solution design into implementation increments. Each increment conforms to the canonical 8-section shape (Identity / Goal / Dependencies / Plan / Outcome / AI Gate / Human Gate / Success Criteria) — see `references/canonical-shapes/canonical-increment-shape.md`.

## Produces
An implementation package per `templates/compositions/greenfield-implementation-package.yaml`, broken into `INC-XXX` increments.

## Consumes
- Approved design package
- Approved requirements package (for FR mapping)

## Skills (populated in task #6)
- `create-implementation-package/` — break design into INC-XXX increments
- `review-implementation-package/` — pre-execution gate (symmetric with requirements/design reviews)
