# References

Cross-cutting framework references loaded by skills on demand. None of these duplicate skill content — they're shared anchors that multiple skills cite.

| Subdir | Purpose |
|---|---|
| `canonical-shapes/` | Canonical structures (e.g., the 8-section increment shape, the per-domain RE shape) |
| `ai-principles/` | Working principles AI-driven skills follow (source-verified facts, scaffold-then-extract, no hallucination, …) |
| `elicitation-patterns/` | Reusable interview prompts (stakeholder discovery, repo scope discovery, change scope discovery) |
| `traceability/` | FR-numbering convention, cross-document index format, ID schemas |
| `glossary-conventions/` | Project-glossary authoring rules |

Skills cite these via relative paths in their `SKILL.md` or `references/` files.
