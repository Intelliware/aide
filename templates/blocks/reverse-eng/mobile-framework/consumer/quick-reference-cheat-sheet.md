```

iOS: import Framework

```

### Basic Setup

```kotlin
// Android
FrameworkConfig.initialize(context, apiBaseUrl)

// iOS
FrameworkConfig.initialize(apiBaseUrl: url)

// React Native
FrameworkConfig.initialize({ apiBaseUrl: url })
```
