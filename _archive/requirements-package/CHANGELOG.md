# Change Log — Standardized Requirements Package

> Tracks all changes made to the requirements-package skill, process document, and template.

| Date | Changed By | What Changed | Files Impacted | Why |
|------|-----------|-------------|----------------|-----|
| 2026-04-21 | Chantelle Gallagher | Added "Step 0: Section Relevance Check" to the 7-Step Workflow — a gate that asks whether each section is relevant before starting work on it. Also integrated the check into Step 5's chunk-by-chunk process. | `phases/create-requirements-package.md`, `skills/create-requirements-package/SKILL.md` | The process had no mechanism to skip irrelevant sections. Users could waste time going through the full 7-step workflow for sections that don't apply to their project. |
| 2026-04-21 | Chantelle Gallagher | Split the monolithic requirements-package-template.md into separate files — one per section (01 through 15, plus appendix-a and 00-index). Deleted the old single-file template. Updated process document and SKILL to reference the multi-file structure as the default. | `templates/` (17 new files created, `requirements-package-template.md` deleted), `phases/create-requirements-package.md`, `skills/create-requirements-package/SKILL.md` | A single large file is harder for AI to work with. Separate files let AI read only the section it needs, improving speed, focus, and context management. |
| 2026-04-21 | Chantelle Gallagher | Removed "Scoring & Ranking Rules" (formerly section 14) entirely. Deleted the template file, removed from index and process document. Renumbered Glossary from 15 to 14. | `templates/14-scoring-ranking-rules.md` (deleted), `templates/15-glossary.md` (renamed to `14-glossary.md`), `templates/00-index.md`, `phases/create-requirements-package.md` | Scoring & Ranking Rules is a project-specific concern, not part of a generic requirements package. Including it biases the template toward a narrow use case. |
| 2026-04-21 | Chantelle Gallagher | Created `requirements-package-completeness-tracker.md` template to track the status of each file (Not Started, In Progress, Skipped, N/A — [reason], Complete). Updated Step 0 to add a "Skip" option and clarified the "Not sure" flow so the user must choose Yes/No/Skip after the explanation. Added instruction to revisit Skipped files at end. | `templates/requirements-package-completeness-tracker.md` (new), `phases/create-requirements-package.md`, `skills/create-requirements-package/SKILL.md` | Needed a single view of progress across all files, and the original Step 0 was missing a "come back later" option and didn't clearly resolve the "Not sure" path. |
| 2026-04-21 | Chantelle Gallagher | Added new "Step 4: File Relevance Recommendation" to the gathering process — after Steps 1-3, AI reviews all template files against gathered context and presents a bulk recommendation (Yes/No/Skip per file) for user confirmation. Renumbered Steps 4-9 to Steps 5-10. Updated Step 0 to clarify it is now primarily used during initial planning (Step 4) and as a per-file fallback during content creation. Updated scaffolding guidance and quick reference checklist. | `phases/create-requirements-package.md`, `skills/create-requirements-package/SKILL.md` | Running Step 0 one file at a time was tedious. A bulk recommendation after gathering enough context lets users review all files at once and react to a plan rather than answer 14+ individual questions. |
