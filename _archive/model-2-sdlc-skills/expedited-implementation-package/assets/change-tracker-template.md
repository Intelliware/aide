# Change Tracker Template

Use this structure to record documentation changes made during expedited implementation planning or execution.

## Change Entries

| Date | Artifact | Section | Change | Impact |
|------|----------|---------|--------|--------|
| YYYY-MM-DD | <artifact> | <section> | <description> | <downstream impact> |

## Notes

- Record material changes to `change-spec`, `codebase-orientation`, or `implementation-plan`.
- Do not use this template for source code commits; the PR workflow owns commit history and PR descriptions.
